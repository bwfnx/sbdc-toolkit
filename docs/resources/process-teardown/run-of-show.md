## Floor-walk cues (3:25–3:40 block)

For anyone stuck, staring at the sheet:

- "What did you do last Friday that you'll do again this Friday?"
- "What's the very first thing you actually touch?"
- "Walk me through it like you're training someone new — what's step one?"

## Share-out prompts

Pull volunteers in worksheet order — process, steps, J/R:

1. "Who wrote down something that happens weekly?"
2. "Who marked a step J that surprised them?"
3. "Who's got an R step they'd actually try before October?"
4. "Who found a step they've been doing by hand that's really just judgment?"

React live on one step per person. J: tell them to keep it, say why. R: give the paste-this on the spot. Don't fix the whole sheet, don't let one person run six minutes.

## Dead-room fallback

If nobody volunteers: "Who has done the same 30-minute task at least four times this month? Shout it out." Then: the one task they'd give away first — no hands, just shout. Take three shouts, react to each, move on.
